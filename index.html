APA YANG BOLEH DICUBA

Enam alat.
Satu ruang kerja.

Setiap kawalan mengubah data pada halaman ini. Cuba terminal, lihat dashboard, kemudian ubah beban trafik.

  1. 01

    Terminal berarahan

    Jalankan deploy, status dan scale dengan sejarah arahan serta pelengkapan Tab. Perubahan terus muncul pada dashboard dan kawalan kapasiti.

    Buka alat
  2. 02

    Auto-Scaling

    Ubah trafik masuk dan lihat instance bertambah apabila CPU melebihi 70%. Matikan penskalaan untuk memeriksa kesan beban berlebihan.

    Buka alat
  3. 03

    Kalkulator kos sumber

    Laraskan projek, storan, trafik dan tahap sokongan. Formula yang sama mengira pecahan kos bulanan serta diskaun tahunan 20%.

    Buka alat
  4. 04

    Peta jarak dan latensi

    Pilih satu daripada lapan bandar dan bandingkan jaraknya ke lokasi lain. JavaScript menggunakan koordinat geografi untuk mengira jarak dan anggaran latensi.

    Buka alat
  5. 05

    Dashboard yang berkongsi data

    CPU model, bilangan instance dan permintaan sesaat mengikuti keadaan setempat. Arahan deploy menambah rekod aktiviti, manakala scale mengubah bilangan instance.

    Buka alat
  6. 06

    Pemeriksaan pelayar

    Periksa keupayaan dan keadaan sebenar pelayar anda. Rekod harian disimpan pada peranti, dan ujian pemulihan menunjukkan peralihan status yang dikawal.

    Buka alat

        Keadaan dikongsi antara alat

      BUTIRAN PROJEK

      Sebelum anda mencuba.

      Cara alat ini berjalan, data yang disimpan dan tempat untuk membaca kod.

      Arahan deploy menambah rekod aktiviti dan mengemas kini keadaan dashboard dalam pelayar. Tiada build atau penerbitan domain dijalankan. Pelaksanaannya boleh dibaca dalam repositori GitHub.

      CPU dan trafik dikira oleh JavaScript setempat untuk menguji interaksi. Bahagian status memeriksa pelayar sebenar dan menyimpan rekod harian pada peranti anda. Halaman ini tidak disambungkan kepada pelayan hosting.

      Tiada bayaran dibuat. Kalkulator menggunakan kadar rujukan dalam satu objek konfigurasi untuk mengira compute, storan, trafik dan sokongan. Suis tahunan menggunakan diskaun 20% pada pengiraan yang sama.

      Halaman ini menggunakan HTML semantik, CSS dan JavaScript biasa dalam satu fail index.html. Carta serta peta menggunakan SVG; Intl memformat nombor dan mata wang.

      Pilihan tema, bahasa dan rekod pemeriksaan harian disimpan dalam localStorage jika tersedia. Keadaan alat berjalan dalam memori pelayar. Borang emel hanya menyemak format dan tidak menghantar alamat anda.

      Tentang projek NimbusCloud

      NimbusCloud ialah projek front-end oleh Putera MY yang menghubungkan enam alat. Terminal, dashboard, kalkulator, penskalaan, peta dan pemeriksaan pelayar berjalan tanpa backend hosting.
