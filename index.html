      Before the first deploy

      Know what happens
      when you click.

      The interface works in your browser. Cloud accounts, payments and support services are not connected.

      The portfolio sequence completes in a few seconds: clone, build, test and release. A real build would depend on source size, dependencies, tests and the selected regions.

      This page does not request source code, credentials or payment information. Theme and language preferences stay in localStorage. Email forms validate locally and send nothing.

      Yes. Select another sample plan at any time. The calculator and selected-plan label update locally; no payment is taken and no subscription is created.

      The fictional platform is designed around Node.js, Python, Go, PHP and container workloads. This portfolio itself uses only HTML, CSS and vanilla JavaScript, with no build step.

      Choose Cancel selected demo plan in the pricing section. Confirm the reset, then use Undo within five seconds if needed. This only resets the page state; there is no real subscription to cancel.
